# 2026-10-10 — 편집 전용 모드를 MarkText 편집 엔진(Muya)으로 교체 (marktext-editor-1of6~6of6, 일괄 승급)

## Plan vs actual
- What went as planned: 소스 이식(고정 커밋 425개 파일 바이트 동일)·마운트·동기화·플러그인 17개·키맵 42개·검색창·이미지 저장이 모두 두 엔진(Chromium·WebKit)에서 필수 48개 통과. 수정 재시도는 한 번도 쓰지 않았다(0/3).
- Divergences:
  - 패치가 계획 1개 → 2개(이미지 경로 + Prism 언어 로딩 경로). 후자는 변이 시험 중 pageerror로 발견했다.
  - TypeScript를 5.6 → 6으로 올렸다(업스트림 컴파일러). 데코레이터는 tsc가 아니라 브라우저 실행에서만 깨졌다.
  - 계약 문장 몇 개가 엔진 실제 동작과 달랐다(이모지 `:smi`, 표 열 툴바, 코드펜스, 하이라이트 직렬화). 계약을 엔진에 맞추지 않고 엔진이 실제로 띄우는 경로로 검사했다.
  - 이미지 경로 선택을 JS 대화상자에서 Rust `pick_image`로 바꿨다(보안 리뷰).

## Learnings
- Do differently next time:
  - 외부 엔진을 "그대로" 이식하는 작업의 검사 계약은, 먼저 엔진을 띄워 실제 DOM·동작을 확인한 뒤에 쓴다. 문장을 먼저 쓰고 엔진을 맞추면 "그대로"와 충돌한다.
  - 디스크에 쓰는 IPC는 구현 직후 적대적 리뷰를 돌린다. 이번에 임시 파일 링크 추종, 드롭 경로 위조, 권한 과다가 모두 실측으로 재현됐다.
  - 이식한 코드를 앱의 tsconfig로 검사하면 업스트림 전역 타입 선언이 include 밖이라 오류가 쏟아진다. 처음부터 `vendor/<x>/src/types`를 include에 넣는다.
  - `pnpm add $변수`는 zsh에서 단어로 나뉘지 않는다. 여러 패키지는 `xargs`로 넣는다.
  - 포트 1420은 다른 프로젝트가 쓰고 있을 수 있다. 하네스 실행기는 빈 포트를 스스로 고른다.
  - 하네스 변이에서 쓴 임시 스크립트는 저장소 루트에 둬야 모듈이 풀리고, 끝나면 지운다.
