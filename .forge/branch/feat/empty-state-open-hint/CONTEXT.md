# markview

macOS용 Tauri 마크다운 뷰어. 이 용어집은 이 프로젝트에서만 통하는 구분만 담는다.

## 언어

**세션**:
앱을 껐을 때 열려 있던 탭의 경로 목록(순서 포함)과 그때의 활성 탭. 탭을 열고 닫고 전환할 때마다 기록되고, 요청 없이 시작할 때 복원된다. 닫은 파일은 세션에 남지 않는다. 최근 파일과 별개다.
_피할 표현_: 작업 상태, 최근 파일

**최근 파일**:
앱이 연 파일 경로의 기록(최근 순, 최대 20개). 닫은 파일도 남고 검색 다이얼로그로 다시 연다. 세션과 달리 "지금 열려 있는지"와 무관하다.
_피할 표현_: 세션, 히스토리
