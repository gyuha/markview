# markview — 브랜치 용어 (feature/ai-edit)

이 파일은 이 브랜치에서 추가·고친 용어만 담는다. 기본 용어집은 `.forge/CONTEXT.md`이고, 이 파일이 우선한다.

## 언어

**프로바이더**:
에이전트 프리셋(Claude Code·Codex·OpenCode)에 사용자의 설정(켜짐 여부·모델·수동 실행 파일 경로)이 붙은 것. 설정 창의 "프로바이더" 탭이 다루고 화면에서는 이 이름을 쓴다. 코드의 `preset`과 같은 대상이다. 사용자가 명령 문자열이나 환경 변수를 정하는 것은 프로바이더가 아니다.
_피할 표현_: 에이전트 종류, 엔진, 커스텀 프로바이더
