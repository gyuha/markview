# markview

macOS용 Tauri 마크다운 뷰어. 이 용어집은 이 프로젝트에서만 통하는 구분만 담는다.

## 언어

**선택 테마**:
사용자가 고른 값. `light` · `dark` · `system` 세 가지뿐이다. 저장되는 것은 이 값이다.
_피할 표현_: 테마, 현재 테마

**실효 테마**:
실제로 화면에 적용되는 값. `light` · `dark` 두 가지뿐이며, 선택 테마가 `system`일 때 OS 외관에서 유도된다. 저장하지 않는다.
_피할 표현_: 테마, 적용 테마, 실제 테마

**원문 보관**:
mermaid 코드블록을 SVG로 바꿔치기할 때 원래 다이어그램 소스를 DOM에 남겨두는 것. 이것이 없으면 테마가 바뀌어도 다시 그릴 수 없다.
_피할 표현_: 캐시, 백업

**재직렬화**:
편집 전용 모드의 Muya가 첫 편집 때 문서 전체를 자기 규칙으로 다시 쓰는 것(리스트 기호·표 정렬 등이 바뀐다). 편집 없이 모드만 오갈 때는 일어나면 안 된다.
_피할 표현_: 포맷팅, 정리, 자동 정렬
