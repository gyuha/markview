# markview

macOS용 Tauri 마크다운 뷰어. 이 용어집은 이 프로젝트에서만 통하는 구분만 담는다.

## 언어

**선택 테마**:
사용자가 고른 값. `light` · `dark` · `system` 세 가지뿐이다. 저장되는 것은 이 값이다.
_피할 표현_: 테마, 현재 테마

**실효 테마**:
실제로 화면에 적용되는 값. `light` · `dark` 두 가지뿐이며, 선택 테마가 `system`일 때 OS 외관에서 유도된다. 저장하지 않는다.
_피할 표현_: 테마, 적용 테마, 실제 테마

**색상 테마**:
`themes/*.yaml` 한 개가 정하는 색 묶음(배경·전경·강조색·터미널 16색). 라이트용과 다크용이 각각 하나씩 저장되고, 그 YAML의 `details` 값(`lighter`/`darker`)이 어느 쪽에 속하는지 정한다. 선택 테마가 정하는 것은 실효 테마이고, 그 실효 테마에 맞는 색상 테마가 실제 색을 정한다.
_피할 표현_: 테마, 스킨, 팔레트

**원문 보관**:
mermaid 코드블록을 SVG로 바꿔치기할 때 원래 다이어그램 소스를 DOM에 남겨두는 것. 이것이 없으면 테마가 바뀌어도 다시 그릴 수 없다.
_피할 표현_: 캐시, 백업

**재직렬화**:
편집 전용 모드의 Muya가 첫 편집 때 문서 전체를 자기 규칙으로 다시 쓰는 것(리스트 기호·표 정렬 등이 바뀐다). 편집 없이 모드만 오갈 때는 일어나면 안 된다.
_피할 표현_: 포맷팅, 정리, 자동 정렬

**에이전트 프리셋**:
앱이 이름을 알고 실행 방법을 아는 AI 에이전트 CLI 하나(Claude Code, Codex, OpenCode). 사용자가 명령 문자열을 직접 정하는 것은 프리셋이 아니다.
_피할 표현_: 에이전트 종류, 엔진, 플러그인

**임시 사본**:
에이전트를 돌리려고 현재 편집 버퍼를 임시 폴더에 쓴 파일. 에이전트는 이것만 고치고, 사용자가 수락하기 전까지 원본은 바뀌지 않는다.
_피할 표현_: 백업, 작업 복사본

**스냅샷**:
에이전트 실행을 시작한 시점의 문서 원문. 결과를 수락할 때 현재 원문과 같은지 비교하는 기준이다.
_피할 표현_: 원본, 버전

**빠른 액션**:
자주 쓰는 지시문을 칩 하나로 묶은 것. 실행할 명령이 아니라 에이전트에 보낼 문장이다.
_피할 표현_: 매크로, 단축 명령
