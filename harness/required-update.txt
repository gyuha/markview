V01  설정 창을 열고(탭이 나뉘어 있으면 모든 탭을 눌러 보며 찾는다) `[data-update]` 업데이트 항목이 보이면, 그 안에 현재 버전이 `plugin:app|version` IPC가 돌려준 값(하네스가 정하는 "1.2.3")으로 `[data-update-version]`에 보이고, 보이는 `[data-update-check]` 확인 버튼이 있으며 `data-update-state`가 idle이다
V02  확인 버튼을 누르면 `check_update` IPC가 정확히 1번 불리고, 응답이 null(새 버전 없음)이면 `data-update-state`가 up-to-date가 되며 "최신" 안내 문구가 보이고 설치 버튼 `[data-update-install]`은 보이지 않는다
V03  `check_update` 응답이 `{ version: "9.9.9", notes: "…" }`이면 `data-update-state`가 available이 되고 새 버전 번호 9.9.9와 노트 내용(`[data-update-notes]`)이 보이며 설치 버튼이 보인다
V04  설치 버튼을 누르면 `install_update` IPC가 1번 불리고, `update-progress` 이벤트(`{ downloaded, total }`)를 보낼 때마다 `[data-update-progress]`의 퍼센트가 그 값(25% → 50% → 100%)대로 바뀌어 보이며(`data-update-state`는 downloading), `install_update`가 끝나면 `data-update-state`가 installed가 되고 재시작 안내가 보인다
V05  `check_update`가 오류로 거부되면 `data-update-state`가 error가 되고 `[data-update-error]`에 오류 내용이 보이며 확인 버튼이 다시 눌린다(페이지 오류 0). `install_update`가 거부돼도 같다
V06  확인 중에는 확인 버튼이, 설치 중에는 설치 버튼이 비활성이라 연타해도 `check_update`는 1번, `install_update`는 1번만 불린다
V07  저장하지 않은 문서(수정됨 탭)가 있을 때 설치 버튼을 누르면 확인 대화상자(`.modal`, `.settings` 아님)가 먼저 뜨고 그동안 `install_update`는 0번이다. 대화상자를 취소하면 계속 0번이고, 확인하면 1번 불린다. 수정된 탭이 없으면 대화상자 없이 바로 1번 불린다
V08  앱을 시작해 기다리고, 설정 창을 열고, 모든 탭을 오가기만 해서는 `check_update`가 한 번도 불리지 않는다(시작·열기로 네트워크 확인을 하지 않는다)
V09  Esc로 설정 창을 닫은 뒤 `update-progress` 이벤트를 보내도 페이지 오류가 나지 않고, 설정 창을 다시 열면 V01 조건(업데이트 항목·버전·확인 버튼)이 다시 성립한다
