T01  `#toolbar-right` 안에 `[data-ontop]` 버튼이 하나 있고, 시작 직후 `aria-pressed`가 "false"이며 `aria-label`과 `title`이 비어 있지 않다
T02  버튼을 누르면 IPC `set_always_on_top`이 정확히 1번 `{ enabled: true }`로 불리고 `aria-pressed`가 "true"가 된다. 한 번 더 누르면 `{ enabled: false }`로 1번 더 불리고 `aria-pressed`가 "false"가 된다
T03  `set_always_on_top`이 오류로 거부되면 `aria-pressed`가 누르기 전 값으로 돌아오고, 오류 알림이 `#notice`에 보이며(hidden 아님, 글자가 있다) 페이지 오류가 0이다
T04  앱을 시작하고, 파일을 열고, 설정 창을 열고 닫고, 탭을 오가기만 해서는 `set_always_on_top`이 한 번도 불리지 않는다(시작할 때 자동으로 고정하지 않는다)
T05  두 창(하네스 `windows`와 같은 방식으로 띄운 서로 다른 창)에서 한 창의 버튼만 켜면 그 창의 IPC만 `{ enabled: true }`로 불리고, 다른 창의 `aria-pressed`는 "false"로 남으며 그 창의 IPC는 0번이다
T06  버튼을 빠르게 두 번 연달아 눌러도 마지막 `aria-pressed` 값이 마지막으로 불린 IPC의 `enabled`와 같다(IPC 응답이 느려도 화면과 IPC 값이 어긋나지 않는다)
T07  버튼이 켜진 상태는 탭 전환, 보기 모드 전환(F1·F2·F3), 테마 전환으로 바뀌지 않고 그동안 `set_always_on_top`은 추가로 불리지 않는다
T08  버튼은 네이티브 `<button type="button">`이고 비활성(`disabled`)이 아니며 `tabindex`가 음수가 아니고 `focus()` 하면 `document.activeElement`가 된다(키보드로 닿고 Enter·Space로 누르는 것은 브라우저 기본 동작에 맡긴다 — 실제 키 입력은 사람 확인 C7에서 본다)
T09  켜진 상태(`aria-pressed="true"`)와 꺼진 상태에서 버튼의 계산된 배경색 또는 글자색이 서로 다르다(눈으로 구별된다). 켜진 상태에서 다크·라이트 테마를 바꿔도 구별이 유지된다
