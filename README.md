# markview

macOS용 마크다운 뷰어. Tauri v2 + TypeScript로 만들었습니다.

파일을 창에 끌어다 놓으면 탭으로 열리고, mermaid 다이어그램과 코드 하이라이팅이 함께 렌더됩니다. 테마는 라이트/다크/시스템 세 가지이고 문서·코드·다이어그램이 한 번에 전환됩니다.

## 설치

[Releases](https://github.com/gyuha/markview/releases)에서 `.dmg`를 받아 `markview.app`을 `/Applications`으로 옮깁니다.

- **macOS, Apple Silicon(arm64) 전용** — Intel Mac에서는 실행되지 않습니다
- **Apple Developer ID로 서명되지 않았습니다.** 처음 열 때 macOS가 차단하므로 앱을 **우클릭 → "열기"** 로 실행하세요(더블클릭이 아닙니다). 또는:

```bash
xattr -dr com.apple.quarantine /Applications/markview.app
```

### `.md` 파일을 markview로 열기

설치하면 우클릭 → "다음으로 열기" 목록에 나타납니다. 더블클릭으로 열리게 하려면 한 번 지정해야 합니다 — macOS는 기존 기본 앱에서 연결을 자동으로 가져오지 않습니다.

`.md` 파일 우클릭 → **정보 가져오기** → **다음으로 열기**에서 markview 선택 → **모두 변경**

## 기능

- **드래그드롭으로 열기** — 여러 파일을 한 번에 놓으면 각각 탭으로 열립니다
- **탭** — 탭마다 스크롤 위치가 보존되고, 같은 파일을 다시 열면 기존 탭이 활성화됩니다
- **테마 3종** — 라이트/다크/시스템. 앱 크롬·문서 본문·코드 하이라이팅·mermaid 다이어그램·에디터가 함께 전환되고, 시스템 모드는 macOS 외관 변경을 즉시 따라갑니다
- **mermaid 다이어그램** — 필요할 때 지연 로드되고, 문법 오류가 있으면 원문 코드블록과 함께 오류를 표시합니다
- **마크다운 확장** — GFM 테이블, 취소선, 체크박스, 헤딩 앵커, frontmatter 숨김
- **raw HTML** — `<details>`나 `<br>` 같은 태그가 원본대로 렌더되고, DOMPurify가 스크립트를 제거합니다
- **상대 경로 이미지**와 링크 — 외부 링크는 기본 브라우저로, 상대 `.md` 링크는 새 탭으로 열립니다
- **창 크기·위치 기억** — 종료 시 저장하고 다음 실행에 복원합니다

## 단축키

| 키 | 동작 |
| --- | --- |
| `⌘E` | 편집 모드 토글 |
| `⌘R` | 현재 탭 새로고침(파일을 다시 읽음) |
| `⌘W` | 현재 탭 닫기 — 마지막 탭이면 창이 닫힙니다 |
| `⇧⌘W` | 창 닫기 |

탭은 가운데 버튼 클릭으로도 닫힙니다.

## 편집 (개발 중)

`⌘E`를 누르면 화면이 좌우로 갈리고 왼쪽 CodeMirror 6 편집기에서 마크다운을 고칠 수 있습니다. 문법 강조와 줄 번호가 있고, 타이핑을 멈추면 오른쪽 프리뷰가 갱신됩니다.

> **저장은 아직 지원하지 않습니다.** 편집한 내용은 앱을 닫으면 사라지고, 파일에 기록되지 않습니다. 저장·미저장 경고·외부 변경 충돌 처리는 다음 작업입니다.

## 직접 빌드

[Rust](https://rustup.rs)와 [pnpm](https://pnpm.io)이 필요합니다.

```bash
pnpm install
pnpm tauri dev                        # 개발 모드로 실행
pnpm tauri build                      # 릴리스 번들(.app + .dmg)
pnpm tauri build --debug --bundles app  # 빠른 .app 번들 (아이콘·파일 연결 확인용)
```

`pnpm tauri dev`는 `.app` 번들이 아니라 실행 파일을 직접 띄우므로 **Dock 아이콘과 파일 연결이 동작하지 않습니다.** 그 두 가지를 확인하려면 번들 빌드가 필요합니다.

## 제약

- Windows·Linux 미지원 (macOS 전용으로 설계했습니다)
- 5MB를 넘는 파일과 폴더는 거부합니다 — 파싱이 프론트엔드에서 일어나므로 큰 파일은 UI를 막습니다
- 파일 변경을 감시하지 않습니다 — 외부에서 고친 내용은 `⌘R`로 다시 읽어야 합니다
- 문서 내 검색, 인쇄/PDF 내보내기, 탭 순서 변경, 세션 복원이 없습니다
- Dock 아이콘에 파일을 떨어뜨려 여는 것은 지원하지 않습니다

## 구성

- **Tauri v2** — Rust는 파일 경로·바이트와 창만 다룹니다. 노출된 커맨드는 `read_markdown` 하나이며 확장자·크기·타입을 검사합니다
- **프론트엔드** — 프레임워크 없이 TypeScript + Vite. markdown-it(파싱) · DOMPurify(sanitize) · highlight.js(코드) · mermaid(다이어그램) · CodeMirror 6(편집)

주요 설계 결정은 [`.forge/adr/`](.forge/adr/)에 기록되어 있습니다 — 마크다운 파싱을 프론트엔드에 둔 이유, 프레임워크를 쓰지 않은 이유, raw HTML을 허용하고 sanitize하는 이유, asset protocol 권한을 실행 시점에 문서 단위로 좁히는 이유.
